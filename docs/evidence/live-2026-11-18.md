## Findings, each to be fixed as code

1. **Argo CD adds finalizers to a child Application with PreDelete hooks,
   so `root` never syncs.** `root` was OutOfSync on `Application/kyverno`
   only. Its `.spec` matched Git; its `metadata.finalizers` had
   `pre-delete-finalizer.argocd.argoproj.io` and
   `pre-delete-finalizer.argocd.argoproj.io/cleanup` besides the
   `resources-finalizer.argocd.argoproj.io` that Git declares. Argo CD adds
   them because the Kyverno chart has a pre-delete hook. Fixed after the
   session: `root` ignores exactly those two finalizers (jq path expression,
   `RespectIgnoreDifferences=true`), checked in CI by
   `ci/check-root-finalizers.py` with a negative case. Ignoring all of
   `/metadata/finalizers` was rejected: a missing `resources-finalizer`
   would no longer show.
